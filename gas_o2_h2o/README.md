# gas_o2_h2o

Математика газоанализатора **«O₂–H₂O»**: пересчёт сырых сигналов ячейки и
датчиков в концентрации газов. Модуль чисто расчётный, к периферии МК не
обращается; данные индивидуальной градуировки вынесены в
`gas_o2_h2o_constants.h` (шаблон — `gas_o2_h2o_constants.h_example`).

## Формулы

### O₂ (твердоэлектролитная ячейка)

```
Cx[%]   = 20.7 · exp(−k(T) · (Ex − Et)),   k(T) = 4F/(R·T)
Cx[ppm] = Cx[%] · 10⁴
```
- `Ex` — ЭДС ячейки, В; `Et` — термоэдс, В;
- коэффициент `k = 4F/(R·T)`; при `T = 907.15 K (634 °C)` он равен `51.17975`;
- **зависимость от температуры:** циркониевая ячейка работает на 634 °C, и
  наклон Нернста `k` зависит от фактической температуры ячейки `T`. Температура
  измеряется термопарой через драйвер **`max31856`**, поэтому для точного
  расчёта O₂ нужно передавать измеренную `T`:
  `GAS_o2_percent_at(ex, et, GAS_kelvin(MAX31856_read_temp()))`.
  Вариант `GAS_o2_percent(ex, et)` использует номинальную `T = GAS_O2_T_NOM`;
- для точного расчёта `Et` определяется и вводится как поправка (`GAS_O2_ET`).

### H₂O (кулонометрический датчик)

```
C_H2O[ppmV] = 747.928 · Ux[В] / Q   ( = 7.47928·10⁻⁴ · Ux[мкВ] / Q )
точно:       = 747.928 · (Ux − Uф) / Q
```
- `Ux` — падение напряжения на резисторе 100 Ом, В;
- `Uф` — напряжение фонового тока, В (`GAS_H2O_UF`);
- `Q` — расход, см³/мин.

### Расход Q

```
Q = a + b·x + c·x²
```
где `x` — выходной сигнал расходомера. Коэффициенты `a, b, c` свои для каналов
O₂ и H₂O и рассчитываются по результатам индивидуальной градуировки.

## Функции

| Функция | Назначение |
| --- | --- |
| `GAS_flow(a,b,c,x)` | расход по произвольному полиному |
| `GAS_flow_o2(x)` / `GAS_flow_h2o(x)` | расход по коэффициентам канала |
| `GAS_kelvin(t_c)` | перевод °C → K (для температуры от MAX31856) |
| `GAS_o2_nernst_k(t_k)` | наклон Нернста `4F/(R·T)` при измеренной T |
| `GAS_o2_percent_at(ex,et,t_k)` / `GAS_o2_ppm_at(...)` | O₂ с учётом измеренной T |
| `GAS_o2_percent(ex,et)` / `GAS_o2_ppm(ex,et)` | O₂ при номинальной T |
| `GAS_h2o_ppm(ux,q)` | концентрация H₂O |
| `GAS_h2o_ppm_corrected(ux,uf,q)` | концентрация H₂O с вычетом фонового тока |

Деление на расход защищено: при `Q = 0` функции H₂O возвращают `0.0f`.

## Замечания

- Часть величин (`GAS_O2_ET`, `GAS_H2O_UF`, коэффициенты полиномов) вводится
  вручную по результатам индивидуальных градуировок — правьте их в
  `gas_o2_h2o_constants.h`.
- Константы заданы с суффиксом `f` (одинарная точность), управляющие
  конструкции в скобках, у функций один выход (MISRA гл. 7, 15). Сборка чистая
  под `-Wall -Wextra -Wconversion -Wpedantic`.
- Используется `expf` из `<math.h>` — при сборке линкуйте `-lm` (на STM32
  обычно входит в стандартную библиотеку).
