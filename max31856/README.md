# max31856

Драйвер прецизионного преобразователя термопары в цифровой код **MAX31856**
(термопары типов B/E/J/K/N/R/S/T, линеаризация) для STM32H7 на LL-драйверах.

Структура повторяет библиотеку `eeprom_mc25lc128`:

- `max31856.c` / `max31856.h` — реализация и публичный интерфейс (адреса
  регистров, битовые поля, прототипы функций);
- `max31856_constants.h` — привязка к периферии МК (экземпляр SPI, вывод CS,
  макросы доступа). В репозитории лежит шаблон `max31856_constants.h_example` —
  скопируйте его в `max31856_constants.h` и поправьте под свою плату.

## Зависимости

Библиотека опирается на низкоуровневые примитивы проекта (как в `MCU/spi.c`):

```c
uint8_t SPI_ReceiveData(SPI_TypeDef* SPIx);
void    SPI_SendData(SPI_TypeDef* SPIx, uint8_t data);
```

SPI должен быть настроен в режиме 1 (CPOL = 0, CPHA = 1), старший бит вперёд,
размер слова 8 бит. Вывод CS — обычный GPIO push-pull выход (программный NSS).

## Использование

```c
#include "max31856.h"

/* термопара типа K, усреднение по 4 отсчётам, непрерывное преобразование */
MAX31856_init(MAX31856_TCTYPE_K, MAX31856_AVG_4);

float t  = MAX31856_read_temp();      // температура спая термопары, degC
float cj = MAX31856_read_cj_temp();   // температура холодного спая, degC

uint8_t fault = MAX31856_read_fault();
if ((fault & MAX31856_FAULT_OPEN) != 0u) {
    MAX31856_clear_fault();           // обрыв термопары: сброс статуса
}
```

Для одиночного измерения вместо непрерывного режима используйте
`MAX31856_oneshot()`, затем считайте температуру после завершения преобразования.

## Функции

| Функция | Назначение |
| --- | --- |
| `MAX31856_write_reg` / `MAX31856_read_reg` | доступ к одному регистру |
| `MAX31856_read_buf` | чтение нескольких регистров с автоинкрементом адреса |
| `MAX31856_probe` | проверка присутствия микросхемы (запись-чтение тестового шаблона, MASK сохраняется/восстанавливается) |
| `MAX31856_init` | задать тип термопары, усреднение и включить непрерывное преобразование |
| `MAX31856_set_filter` | подавление 50/60 Гц; на время смены останавливает преобразования (требование даташита) и восстанавливает режим |
| `MAX31856_set_tc_limits` | пороги аварий по термопаре, °C (LSB 0.0625 °C, с клампом) |
| `MAX31856_set_cj_limits` | пороги аварий холодного спая, °C (LSB 1 °C) |
| `MAX31856_set_cj_offset` | поправка холодного спая CJTO, °C (LSB 0.0625 °C) |
| `MAX31856_oneshot` | запустить одиночное преобразование (не блокирует) |
| `MAX31856_conversion_done` | опрос завершения одиночного преобразования (бит 1SHOT) |
| `MAX31856_clear_fault` | сбросить статус аварий (бит FAULTCLR) |
| `MAX31856_read_fault` | прочитать регистр статуса аварий (SR) |
| `MAX31856_read_temp` / `MAX31856_read_cj_temp` | температура в degC (float) |
| `MAX31856_read_temp_raw` / `MAX31856_read_cj_temp_raw` | знаковый код регистра (int32_t) без плавающей точки |

## Вызов из прерываний и из задач RTOS

Внутри функций нет задержек и ожиданий — только короткие побайтовые обмены по
SPI, поэтому их можно звать из периодического прерывания (циклограмма):

```c
/* цикл одиночных измерений в тике планировщика/прерывании */
switch (state) {
case START:  MAX31856_oneshot(); state = WAIT; break;
case WAIT:   if (MAX31856_conversion_done() == 1U) { state = READ; } break;
case READ:   t = MAX31856_read_temp(); state = START; break;
}
```

Под FreeRTOS тот же опрос оборачивается в задачу с `vTaskDelay` между
`conversion_done`. Функции не реентерабельны: если к SPI-шине обращаются
несколько задач — защитите обмен мьютексом на стороне приложения. После
инициализации шины полезно вызвать `MAX31856_probe()` и не запускать задачу
опроса, если чип не ответил.

Варианты `*_raw` возвращают целочисленный код регистра — для прошивок, где
работа с плавающей точкой нежелательна; цена разряда задана в `MAX31856_TC_LSB`
и `MAX31856_CJ_LSB`.

## Соответствие MISRA / LL

- Регистровые и битовые константы заданы с суффиксом `U` (MISRA гл. 7), все
  управляющие конструкции в скобках, у функций один выход (гл. 15, 16), условия
  записаны как явные сравнения с `0`.
- LL-вызовы вынесены в `max31856_constants.h` (CS через `LL_GPIO_*`), обмен по
  SPI идёт через примитивы проекта `SPI_SendData` / `SPI_ReceiveData`
  (`MCU/spi.c`), как в примере `cryomm_part`. Сама библиотека от заголовков LL
  не зависит и не дублирует их.
- Код собирается без замечаний под `-Wall -Wextra -Wconversion -Wpedantic`.

## Регистры и формат данных

- Линеаризованная температура термопары (`LTCBH/LTCBM/LTCBL`) — 19-битное
  знаковое значение, цена младшего разряда 2^-7 = 0.0078125 °C.
- Температура холодного спая (`CJTH/CJTL`) — 14-битное знаковое значение,
  цена младшего разряда 2^-6 = 0.015625 °C.

Адрес записи регистра формируется как `адрес_чтения | MAX31856_WRITE_ADDR` (|0x80).
