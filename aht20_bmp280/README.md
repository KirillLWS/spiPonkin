# aht20_bmp280

Полный драйвер комбинированного модуля **AHT20 + BMP280** (температура,
влажность, давление) по шине **I²C** для STM32H7 на LL. Обе микросхемы висят на
одной шине с разными адресами.

Структура — как у остальных библиотек: основные файлы + файл констант
(`aht20_bmp280_constants.h`, шаблон — `..._constants.h_example`).

## Зависимости

- `i2c/` — транспорт I²C (`I2C_Write` / `I2C_Read` / `I2C_WriteRead`) на LL, с
  таймаутами и детектом NACK; возвращает `I2C_Status`.
- `gpio/` — универсальная настройка выводов (для линий SCL/SDA).
- Сама шина (тактирование, `TIMINGR`, выводы) настраивается в проекте; драйвер
  только ведёт транзакции. Задержки — через `AHT_BMP_DELAY_MS` (`LL_mDelay`).

## Адреса и константы (`aht20_bmp280_constants.h`)

```c
#define AHT_BMP_I2C   I2C1
#define AHT20_ADDR    0x38U   // фиксированный
#define BMP280_ADDR   0x76U   // 0x77, если SDO подтянут к VCC
#define AHT_BMP_DELAY_MS(ms)  LL_mDelay(ms)
```

## Использование

```c
#include "gpio.h"
#include "aht20_bmp280.h"

/* Выводы I2C1: PB6=SCL, PB9=SDA — альтернативная функция, открытый сток,
   подтяжка вверх. Универсальная функция закрывает любой режим одним вызовом: */
GPIO_Config(GPIOB, LL_GPIO_PIN_6 | LL_GPIO_PIN_9,
            LL_GPIO_MODE_ALTERNATE, LL_GPIO_OUTPUT_OPENDRAIN,
            LL_GPIO_PULL_UP, LL_GPIO_SPEED_FREQ_VERY_HIGH, LL_GPIO_AF_4);
/* ... далее настройка самого I2C1 (TIMINGR, Enable) в проекте ... */

float t_aht, rh, t_bmp, press;

if (AHT20_init() == I2C_OK) {
    (void)AHT20_read(&t_aht, &rh);      // degC, %
}
if (BMP280_init() == I2C_OK) {
    (void)BMP280_read(&t_bmp, &press);  // degC, Pa
}
```

Любой из указателей в `*_read` можно передать `NULL`, если значение не нужно.

## Функции

| Функция | Назначение |
| --- | --- |
| `AHT20_init()` | пауза на старт, проверка калибровки, при необходимости калибровка |
| `AHT20_soft_reset()` | программный сброс (0xBA, ~20 мс) — лечит зависший датчик без снятия питания; после него нужен `AHT20_init()` |
| `AHT20_trigger()` | **неблокирующий** запуск измерения (~80 мс в чипе) |
| `AHT20_busy(&b)` | **неблокирующий** опрос: идёт ли ещё преобразование |
| `AHT20_fetch(&t,&rh)` | **неблокирующее** чтение готового результата с проверкой CRC |
| `AHT20_read(&t,&rh)` | блокирующий цикл: trigger + ожидание + fetch (для задачи RTOS) |
| `BMP280_init()` | проверка chip id (0x58), сброс, чтение калибровки, нормальный режим |
| `BMP280_read(&t,&p)` | компенсированные температура (°C) и давление (Па); без ожиданий |

Коды возврата: `I2C_ERR_TIMEOUT` из `AHT20_fetch` — «ещё преобразует, зайди
позже»; `I2C_ERR_DATA` — CRC не сошёлся (AHT20) или пропущенное измерение
`0x80000` (BMP280); `I2C_ERR_NACK` — датчик не отвечает на шине.

## Вызов из прерываний и из задач RTOS

- **Циклограмма/прерывания:** используйте тройку `AHT20_trigger` →
  `AHT20_busy`/`AHT20_fetch` — внутри нет ни одной задержки. `BMP280_read`
  можно звать напрямую: в нормальном режиме чип меряет сам, чтение мгновенное.
- **FreeRTOS-задача:** используйте блокирующий `AHT20_read`, а макрос задержки
  в `aht20_bmp280_constants.h` переопределите, чтобы задача уступала процессор:
  `#define AHT_BMP_DELAY_MS(ms) vTaskDelay(pdMS_TO_TICKS(ms))`.
  Сам FreeRTOS в репозиторий не входит — это только точка подмены.
- Транспорт I²C не реентерабельный: несколько задач на одной шине — мьютекс на
  стороне приложения.
- После сбоя/сброса МК зависшую шину лечит `I2C_BusRecover(...)` из `i2c/`
  (9 тактов SCL + STOP), затем повторная инициализация выводов в AF.

## Детали реализации

- **AHT20:** инициализация `0xBE 0x08 0x00`, запуск `0xAC 0x33 0x00`, чтение 7
  байт; влажность = `raw/2²⁰·100 %`, температура = `raw/2²⁰·200 − 50 °C`;
  проверяется CRC-8 (полином `0x31`, старт `0xFF`) и бит занятости.
- **BMP280:** компенсация температуры (int32, 0.01 °C) и давления (int64,
  Q24.8 Па) — точно по формулам даташита. Коэффициенты калибровки читаются из
  регистров `0x88…0x9F` и хранятся в модуле; `t_fine` от температуры
  используется в расчёте давления, поэтому температура считается первой.
- Математика проверена на эталонных значениях даташита BMP280:
  `T = 25.08 °C`, `P = 100653 Па`.
- Транспорт I²C защищён таймаутом (шина не «подвесит» прошивку) и различает
  NACK — можно детектировать отсутствие датчика.
- Стиль под MISRA (гл. 7, 15, 16), сборка чистая под
  `-Wall -Wextra -Wconversion -Wpedantic`.
